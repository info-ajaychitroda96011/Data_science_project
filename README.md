# 🎓 Student Exam Performance Indicator

## 📘 Project Overview
Student Exam Performance Indicator is a Machine Learning–based web application that predicts a student’s **Maths score** using demographic and academic features such as gender, parental education, lunch type, and previous reading and writing scores.

The **primary goal of this project** is to understand and implement an **industry-level Machine Learning project structure**, focusing on modular coding, logging, exception handling, and end-to-end ML pipelines.

---

## 🎯 Project Objectives
- Learn **end-to-end Machine Learning project workflow**
- Implement **clean and scalable project structure**
- Practice **modular coding principles**
- Understand **ML pipelines for training and prediction**
- Build a **Flask-based web application**
- Implement **logging and custom exception handling**
- Prepare an ML project for **production readiness**

---

## 🧠 Machine Learning Approach
- **Problem Type:** Regression  
- **Target Variable:** Maths Score  

### 🔹 Input Features
- Gender  
- Race / Ethnicity  
- Parental Level of Education  
- Lunch Type  
- Test Preparation Course  
- Reading Score (0–100)  
- Writing Score (0–100)  

### 🔹 ML Pipeline
- Data ingestion  
- Data cleaning and preprocessing  
- Feature transformation  
- Model training and evaluation  
- Model serialization  
- Prediction pipeline for inference

This project follows a **production-ready ML architecture** to ensure scalability and maintainability.
